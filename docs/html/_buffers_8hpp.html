Detailed Description

Defines the engine's concrete GPU buffer aliases (VertexBuffer, IndexBuffer, UniformBuffer, StorageBuffer) as GpuBuffer specializations.

Each alias fixes the GL target and binding mode for a buffer role, so callers get the right bind() overload and type safety by construction.
