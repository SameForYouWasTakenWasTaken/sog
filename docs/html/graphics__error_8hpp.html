enum class sog::graphics_error_code
strong

Machine-readable codes describing why a graphics operation failed.

Each enumerator corresponds to a distinct class of graphics failure (window creation, shader compilation, buffer/texture/framebuffer state, etc.) so that callers can branch on the failure kind via graphics_error::code() without parsing the human-readable message.

Enumerator
window_creation_failed 

The window (and its OpenGL context) could not be created.

invalid_operation 

An OpenGL operation was attempted in an invalid state.

shader_compilation_failed 

A shader stage failed to compile.

shader_link_failed 

A shader program failed to link.

buffer_creation_failed 

An OpenGL buffer object could not be created.

vertex_array_creation_failed 

A vertex array object could not be created.

vertex_array_not_bound

buffer_not_bound 

An operation required a bound buffer, but none was bound.

uniform_location_invalid

shader_file_open_failed 

A shader source file could not be opened for reading.

invalid_shader_program

texture_load_failed

texture_not_bound
