◆ setDebugCallback()

void sog::debug::setDebugCallback ( DebugCallback callback)

Stores the user callback and enables OpenGL debug output.

Registers a handler for OpenGL debug messages and enables debug output.

Parameters
callbackHandler to receive translated debug messages (moved into a module-level slot).

Installs internalOpenGlBridge as the GL debug callback, then enables GL_DEBUG_OUTPUT and GL_DEBUG_OUTPUT_SYNCHRONOUS.

Stores the callback, installs an internal bridge with glDebugMessageCallback and enables GL_DEBUG_OUTPUT (plus synchronous output for reliable debuggers). Every subsequent GL debug message is translated and forwarded to callback.

Parameters
callbackHandler to receive translated debug messages; replaces any previous one.
Note
Requires a debug context (the engine requests one in Window::initialize via GLFW_OPENGL_DEBUG_CONTEXT).
