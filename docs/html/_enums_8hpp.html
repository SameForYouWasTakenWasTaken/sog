◆ buffer_usage

enum class sog::gfx::buffer_usage : GLenum
strong

Expected usage pattern of a buffer, guiding GL driver storage (mirrors GL_*_DRAW/READ/COPY).

Hints only — they do not change correctness. STREAM means the data changes once and is used a few times, DYNAMIC a few times, STATIC many times; DRAW consumes the data for rendering, READ is read back by the client, COPY is reused as source data for other GL commands.

Enumerator
STREAM_DRAW 

Modified once, consumed a few times for drawing.

STREAM_READ 

Modified once, then read back a few times.

STREAM_COPY 

Modified once, then used as source data a few times.

DYNAMIC_DRAW 

Modified a handful of times, consumed many times for drawing.

DYNAMIC_COPY 

Modified a handful of times, then used as source data repeatedly.

DYNAMIC_READ 

Modified a handful of times, then read back repeatedly.

STATIC_DRAW 

Modified once at creation, consumed many times for drawing.

STATIC_COPY 

Modified once at creation, then used as source data repeatedly.

STATIC_READ 

Modified once at creation, then read back repeatedly.

◆ texture_min_filters

enum class sog::gfx::texture_min_filters : GLint
strong

Minification filters for textures, including mipmap-aware variants (mirrors GL_NEAREST, GL_LINEAR and the GL_*_MIPMAP_* combinations).

The mipmapped entries select between two mip levels by distance (LINEAR) or pick the nearest level and filter within it (NEAREST).

Enumerator
NEAREST 

Closest texel; blocky when magnified/minified.

LINEAR 

Bilinear interpolation between texels.

NEAREST_MIPMAP_NEAREST 

Nearest mip level, nearest texel within it.

LINEAR_MIPMAP_NEAREST 

Nearest mip level, linear filtering within it.

NEAREST_MIPMAP_LINEAR 

Linear blend between the two nearest mip levels, nearest texel.

LINEAR_MIPMAP_LINEAR 

Trilinear filtering: linear across mip levels and within each.

◆ texture_mipmaps

enum class sog::gfx::texture_mipmaps : GLenum
strong

Mipmap level-selection strategies derived from the minification filter (mirrors the GL_*_MIPMAP_* constants).

Names follow the "level filter, within-level filter" convention: LINEAR_NEAREST blends linearly between mip levels but samples the nearest texel inside each level, and so on.

Enumerator
NEAREST 

Nearest level, nearest texel within it.

LINEAR_NEAREST 

Nearest level, linear texel filtering within it.

NEAREST_LINEAR 

Linear level blend, nearest texel within levels.

LINEAR_LINEAR 

Trilinear: linear level blend and linear texel filtering.
