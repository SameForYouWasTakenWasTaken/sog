Detailed Description

Defines GLHandle<Tag>, a move-only typed wrapper around a raw OpenGL object name.

The Tag parameter is a phantom type: it makes handles for different GL object kinds (buffers, textures, shaders, ...) mutually non-convertible even though every handle stores the same underlying GLuint.
