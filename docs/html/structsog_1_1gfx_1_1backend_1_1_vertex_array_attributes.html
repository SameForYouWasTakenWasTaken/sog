Detailed Description

Describes the layout of a single vertex attribute within a vertex buffer.

Mirrors the arguments of glVertexAttribPointer()/glVertexAttribIPointer(): which attribute slot (index), how many components (size), their component type (type), whether integers are normalized (normalized), the byte step between vertices (stride), the byte offset of the first element (offset) and the buffer binding point the attribute reads from (binding).

See also
sog::Vertex::attributes() for the engine's canonical attribute set
