Detailed Description

Declares the sog::input keyboard/mouse query API, including per-frame edge detection, cursor tracking and a camera controller helper.

Split into two styles: immediate queries (isKeyDown, isMouseButtonDown, getCursorPosition) that read live GLFW state and need no update(), and edge-triggered queries (isKeyPressed/Released, getCursorDelta) that diff the snapshot taken by update() against the previous frame's.

◆ update()

void sog::input::update ( const gfx::Window & window)

Snapshots the current key/mouse/cursor state for edge-triggered queries.

Parameters
windowWhose native input is sampled.

Call once per frame, immediately after Window::pollEvents(). Advances the previous-state buffers, polls every key and mouse button, and computes the cursor delta since the prior update (zero on the very first update, to avoid a spurious jump).

Drives a Camera from the keyboard: WASD to move, Space/Ctrl for up/down, arrows to look.

Parameters
cameraCamera to manipulate in place.
windowWhose input is read (live queries).
dtFrame delta time in seconds; scales movement and turning for frame-rate independence.
moveSpeedUnits per second of horizontal/vertical movement (default 5).
turnSpeedDegrees per second of arrow-key turning (default 90).

Movement is normalized so diagonal travel is not faster, and pitch is clamped to +/-89 degrees to avoid flipping. Call after update() if you also need edge-triggered queries the same frame; the movement/look reads use live state.
