Detailed Description

Owns a GL framebuffer object (FBO) for rendering offscreen.

The constructor creates the FBO immediately; attach textures or renderbuffers with the attach* methods, check isComplete() before rendering into it, and bind() it to redirect drawing. Rendered contents can then be sampled as a texture (e.g. for post-processing). Destruction releases the GL object.

All attach* methods use GL's direct-state-access entry points, so the FBO does not need to be bound to attach a resource.

Attention
An FBO is only usable for rendering once it is complete (isComplete() returns true); attaching only a color texture with no depth/ stencil where the shader expects one can leave it incomplete.
See also
sog::FramebufferAttachment, sog::RenderBuffer
