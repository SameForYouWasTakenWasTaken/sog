Detailed Description

Owns a GLFW window and its OpenGL context, and drives the per-frame render loop.

Construction initializes GLFW (throwing sog::graphics_error on failure), creates the window with the requested context::WindowContext, makes the context current and loads GL entry points via glad. Destruction destroys the GLFW window.

Typical frame loop:

while (!window.shouldClose())
{
window.beginFrame(ClearBuffer::Color | ClearBuffer::Depth, {0, 0, 0, 255});
Window::draw(state);
window.endFrame();
}

beginFrame() clears the requested buffers with the given color; endFrame() swaps the buffers and polls native events. The engine's own Event queue is fed by callbacks (e.g. resize) and drained with pollEvent().

Clear colors are plain sog::Color values on the 0-255 scale, exactly like every other Color in the API; beginFrame()/clear() normalize them internally before calling glClearColor.
