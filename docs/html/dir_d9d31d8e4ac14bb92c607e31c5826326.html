Files

 		FrameBuffer.hpp
 Defines FrameBuffer, a RAII wrapper around a GL framebuffer object for offscreen rendering, plus the FramebufferAttachment enum for slot selection.
 		Shader.hpp
 Defines the Shader<Stage> template (compile a GL shader stage from source or file), plus the VertexShader and FragmentShader aliases and a compile-status error helper.
 		ShaderProgram.hpp
 Defines ShaderProgram, a linked GL program that attaches shader stages, binds for drawing and caches uniform locations.
 		Texture2D.hpp
 Defines Texture2D, a RAII 2D texture that loads from file (via stb_image) or raw pixel data, with configurable sampling settings.
 		TextureSettings.hpp
 Defines TextureSettings, a plain struct collecting the sampling parameters (wrap modes, filters, mipmap options) applied to a texture.
 		VertexArray.hpp
 Defines VertexArray, a RAII wrapper around a GL vertex array object that binds vertex/index buffers and configures attribute formats.
 		VertexArrayAttributes.hpp
 Defines backend::VertexArrayAttributes, a plain-data description of one vertex attribute layout (index, size, type, stride, offset, binding).
