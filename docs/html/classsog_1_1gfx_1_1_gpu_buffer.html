Detailed Description

template<typename T, GLenum Target, BindingMode BindMode>
class sog::gfx::GpuBuffer< T, Target, BindMode >

Typed, automatically growing GPU buffer with element-level accessors.

Wraps backend::GLBuffer (byte storage with immutable GL 4.5 allocation) and adds an element count and capacity. set() replaces the whole contents and grows the buffer as needed; push() appends, growing geometrically; update() overwrites an existing sub-range in place. Capacity is measured in elements, storage in bytes.

The bind() overload available depends on BindMode (a C++20 requires clause selects one): Regular buffers bind to a target, Indexed buffers bind to a binding point. Element type T must be trivially copyable (enforced by static_assert) because it is uploaded to the GPU as raw bytes.

Template Parameters
TElement type stored in the buffer (e.g. Vertex, or a uniform struct).
TargetGL target to bind to (GL_ARRAY_BUFFER, GL_UNIFORM_BUFFER, ...).
BindModeBindingMode::Regular or BindingMode::Indexed.
Attention
set() with a smaller range shrinks the logical size but not the GPU allocation; use reserve() only to grow, and note clear() resets the element count without touching stored data.
See also
sog::VertexBuffer, sog::IndexBuffer, sog::UniformBuffer (Buffers.hpp)
