◆ SetRenderingState()

void sog::gfx::SetRenderingState ( const RenderSettings & settings)
inline

Applies a RenderSettings struct to the current GL context's global state.

Translates each boolean into the corresponding glEnable/glDisable via backend::set: depth testing (GL_DEPTH_TEST), blending (GL_BLEND) and face culling (GL_CULL_FACE). Call once per frame or on state changes.

Parameters
settingsDesired state; each field maps to one GL capability.
