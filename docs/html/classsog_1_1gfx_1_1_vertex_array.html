Detailed Description

Owns a GL vertex array object (VAO) and configures how vertex data is read.

create() allocates the VAO (no-op if one already exists). The set* methods use GL's direct-state-access entry points to attach a vertex buffer, attach an index buffer and apply a set of attribute formats without requiring the VAO to be bound first. bind() makes the VAO current; the constructor/destructor manage the GL object's lifetime.

Attaching an index buffer via setIndexBuffer() also records the element count, which indexed() and indexCount() expose; Window::draw() uses this to choose glDrawElements over glDrawArrays.

The class is move-only; the GL object is deleted on destruction or release().

See also
sog::VertexArrayAttributes, sog::VertexBuffer, sog::IndexBuffer
