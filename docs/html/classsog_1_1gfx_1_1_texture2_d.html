Detailed Description

Owns a GL 2D texture and manages its creation, upload and binding.

createFromFile() decodes an image with stb_image (flipping vertically to match GL's bottom-left origin), converting everything to RGBA8, then uploads it via createFromRaw(). createFromRaw() allocates immutable storage (DSA glTextureStorage2D), uploads the pixel data if provided, applies the wrap and filter settings from TextureSettings, and generates mipmaps if requested.

empty() is a convenience factory for an uninitialized texture of a given size (e.g. a render target), and bind() binds the texture to a sampler unit using glBindTextureUnit (DSA).

The class is move-only: destruction (or release()) deletes the GL texture, and moving transfers ownership.

Attention
Mipmap generation only happens when both generateMipmaps is set AND pixel data was supplied; allocating storage alone (data == nullptr) leaves the chain ungenerated and sampling may look wrong if a mip filter is selected.
