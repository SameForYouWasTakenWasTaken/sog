Detailed Description

template<typename T>
class sog::gfx::backend::GLBuffer< T >

Owns one OpenGL buffer object with immutable storage (DSA-style, GL 4.5+).

Creates the buffer with glCreateBuffers + glNamedBufferStorage, deleting it on destruction. Storage is immutable per the GL spec, so resize() implements "growing" by allocating a fresh buffer and GPU-copying the old contents into it. Copying is disabled; moving transfers the handle.

The class is used through the higher-level sog::GpuBuffer, which tracks element counts and capacity on top of this byte-oriented buffer.

Template Parameters
TElement type of the data stored (used for the typed handle only; this buffer is byte-addressed via write()).
Attention
write() asserts that byteOffset + bytes does not exceed the current size; the check is compiled out in release builds.
See also
sog::GpuBuffer

◆ resize()

template<typename T>
void sog::gfx::backend::GLBuffer< T >::resize ( size_t newBytes,
bool keepContents )
inline

Reallocates the buffer to a new byte size, optionally copying old contents.

Because GL 4.5 storage is immutable, this creates a new buffer of newBytes (with the original creation flags), copies min(old size, newBytes) bytes across on the GPU when keepContents is true and a source exists, then swaps the new buffer in and destroys the old one.

Parameters
newBytesNew storage size in bytes.
keepContentsWhether to copy the old contents into the new buffer.
