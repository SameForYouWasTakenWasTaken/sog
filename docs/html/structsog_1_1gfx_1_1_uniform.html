Detailed Description

Location of a uniform within a linked shader program.

Wraps the GLint returned by glGetUniformLocation. A location of -1 means the uniform does not exist in the program (or is unused/optimized out); valid(), operator bool and the explicit conversion to Location let callers check before setting values.

See also
sog::ShaderProgram::getLocation, sog::uniform::getLocation
