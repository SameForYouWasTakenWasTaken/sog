Detailed Description

Private pimpl holding the native GLFWwindow and its resize callback.

The resize callback (on_resize) is registered via glfwSetFramebufferSizeCallback; it recovers the owning Window from the GLFW user pointer, updates the stored dimensions, resizes the GL viewport and enqueues an EventType::Resized event (ignored while minimized, i.e. size 0).
