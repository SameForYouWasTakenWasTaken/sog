Detailed Description

Owns a GL renderbuffer object for offscreen storage of a fixed format and size.

Unlike a texture, a renderbuffer's contents cannot be sampled directly; it is meant to be attached to a framebuffer (e.g. as depth/stencil storage). Storage is allocated at construction or via create() using GL's direct-state-access glNamedRenderbufferStorage, so it need not be bound.

The object is move-only; destruction or release() frees the GL renderbuffer and resets the recorded dimensions and format.
