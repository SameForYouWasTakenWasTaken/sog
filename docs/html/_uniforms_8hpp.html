Detailed Description

Declares the sog::gfx::uniform free-function API for looking up and uploading typed values to shader uniforms.

These helpers use GL's direct-state-access program-uniform entry points (glProgramUniform*), so the program need not be bound first. Each setter validates the uniform's location and throws on an invalid one.

template<typename... T>
void sog::gfx::uniform::runSafe ( T &&... cb)

Runs a list of callables, ignoring any exception each one throws.

Executes each callback in order inside its own try/catch, so one throwing call does not abort the remaining ones. This is by design: a failing step (e.g. a missing optional uniform) should not stop the rest of the frame.

Template Parameters
TCallable types.
Parameters
cbZero or more callables to invoke in sequence.
