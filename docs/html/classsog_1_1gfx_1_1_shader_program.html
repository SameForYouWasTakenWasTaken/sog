Detailed Description

A linked OpenGL shader program owning two shader stages.

The constructor creates the GL program object. Initialize() attaches two compiled shaders (of any two distinct stage types), links the program and validates the link, throwing sog::graphics_error with the driver's info log on failure. use() makes the program current for drawing.

Uniform locations are looked up through getLocation(), which caches results by name so repeated per-frame uniform updates avoid redundant glGetUniformLocation calls.

Attention
The program is created eagerly in the constructor but is only usable after Initialize() links it. The attached shader objects remain owned by the caller.
