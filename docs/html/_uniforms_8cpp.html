Detailed Description

Implements the sog::gfx::uniform helpers: uniform lookup plus typed uploads via GL's direct-state-access glProgramUniform* entry points.

◆ getLocation()

Uniform sog::gfx::uniform::getLocation ( const ShaderProgram & program,
const std::string & name )
nodiscard

Looks up a uniform's location by name within a linked program.

Parameters
programThe linked shader program to query.
nameThe uniform's name as declared in the shader.
Returns
Uniform holding the location; may be invalid (-1) if not found.
Note
Does not throw for a missing uniform — callers get an invalid Uniform to test. Prefer ShaderProgram::getLocation, which caches results per program.
