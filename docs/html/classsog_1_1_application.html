Detailed Description

Top-level demo application: owns the main loop that renders a textured cube with a post-processing pass.

Constructing an Application performs no setup (defaulted constructor); all resource creation and the render loop live in Run(). Run() builds the window, geometry, shaders, texture and an offscreen framebuffer, then loops until the window is closed, rendering the scene into the framebuffer and applying a full-screen post-processing effect before swapping.
