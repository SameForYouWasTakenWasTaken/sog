Detailed Description

Umbrella header of the sog library: pulls in the public API and re-exports the most commonly used types into the top-level sog:: namespace.

Including <sog/sog.hpp> gives a program the whole library surface: windowing (Window, Event, ClearBuffer), drawing (VertexArray, buffers, shaders, Texture2D, FrameBuffer, RenderBuffer, Uniform), the Camera, input queries (Input.hpp) and the Utility helpers (Math, Time, Uniforms).

Types live in sog::gfx (and its inline namespaces); the aliases declared here let typical application code use the short names (sog::Window, sog::Vertex, sog::ShaderProgram, ...) without naming the gfx namespace. The enums and uniform helpers are additionally re-exported as sog::enums and sog::uniform.
