enum class sog::gfx::ClearBuffer : unsigned int
strong

Which framebuffer buffer(s) to clear, mirroring the GL_COLOR_BUFFER_BIT / GL_DEPTH_BUFFER_BIT / GL_STENCIL_BUFFER_BIT flags.

Values are the raw GL bit masks, so a combination can be passed straight to glClear. Combine members with operator| (e.g. ClearBuffer::Color | ClearBuffer::Depth).
