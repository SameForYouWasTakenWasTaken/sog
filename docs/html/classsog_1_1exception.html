Detailed Description

Base class for all exceptions thrown by the sog engine.

Extends std::exception with a descriptive message and the std::source_location where the exception was created, so failures can be reported with file, line and function without the caller threading that information manually. All engine exception types (sog::runtime_error, sog::graphics_error, ...) derive from this.

The message is stored by value (an owning std::string), so the exception is fully self-contained: the backing string may safely be a temporary.

See also
sog::runtime_error, sog::graphics_error
