Detailed Description

Exception type for graphics/OpenGL failures, carrying a graphics_error_code.

Derives from sog::exception, so it also captures the human-readable message and the std::source_location of the throw site. Use code() to branch on the failure kind programmatically.

See also
sog::exception, sog::graphics_error_code
