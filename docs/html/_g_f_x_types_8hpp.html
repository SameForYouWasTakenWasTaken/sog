Detailed Description

Type aliases mapping engine graphics vocabulary onto raw OpenGL typedefs (handles, vertex-attribute parameters, buffer sizes).

These aliases let engine code speak in domain terms (attribute_index, buffer_size) while remaining ABI-identical to the underlying GL types.
