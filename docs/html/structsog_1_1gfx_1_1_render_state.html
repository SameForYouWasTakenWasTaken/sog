Detailed Description

Everything Window::draw() needs to render one batch.

Holds references (not owning) to the vertex buffer and vertex array backing the geometry, an optional texture, and the linked shader program to use. Pass an instance to Window::draw(), which binds the program and vertex array, optionally binds the texture to unit 0, and issues either glDrawElements or glDrawArrays depending on whether the vertex array has an index buffer.

Attention
All reference members must outlive the RenderState and the draw call; this struct never extends their lifetime. texture2D may be null for untextured draws.
