Detailed Description

Sampling configuration applied to a texture when its storage is created.

Groups the wrap modes for each axis, the minification and magnification filters, and the mipmap options. Defaults repeat and use linear filtering with mipmapping disabled.

See also
sog::Texture2D::createFromFile, sog::Texture2D::createFromRaw
