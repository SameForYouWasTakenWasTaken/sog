Detailed Description

A single vertex: 3-float position, 4-float color, 2-float texture coordinate.

Layout is fixed and interleaved in this member order, so sizeof(Vertex) is the stride for every attribute. attributes() returns the matching backend::VertexArrayAttributes array (positions at location 0, colors at 1, texcoords at 2) for configuring a vertex array object against a shader program that uses the same locations.

See also
sog::backend::VertexArrayAttributes, sog::VertexArray
