Detailed Description

RGBA color stored as normalized floats (0.0 - 1.0 per channel).

Matches the component range expected by OpenGL (e.g. glClearColor, glClear), so a Color can be handed straight to the API. Use fromRGBA() to build a color from conventional 8-bit values.

Attention
The members are assumed to be normalized floats in [0, 1]. See toRGBA() for the (unexpected) behaviour of that helper before using it.

Returns
Color whose members hold the rounded 0-255 values as floats.
Attention
Despite the name, this does not produce 8-bit integers; it returns a Color whose float members are scaled to 0-255. The result is only suitable as an intermediate for further conversion (e.g. before writing bytes to disk), not for direct use with OpenGL calls that expect normalized [0, 1] colors.
