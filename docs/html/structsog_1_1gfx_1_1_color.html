Detailed Description

RGBA color on the conventional 8-bit-per-channel scale (0 - 255 per channel).

Matches how people naturally write colors ({255, 128, 0} orange, like a color picker or CSS), so a Color literal reads the way it looks. Internals hand the value to OpenGL through normalized() (or the explicit Vec4 conversion), which divides each channel by MAX_VALUE into the [0, 1] range glClearColor and friends expect — callers never divide by hand.

fromRGBA() constructs from uint8_t-typed sources (e.g. image data), and toRGBA() converts back to bytes (e.g. for serialization).
