Detailed Description

template<typename Tag>
class sog::gfx::GLHandle< Tag >

Move-only RAII-style name holder for an OpenGL object.

Owns nothing beyond the GLuint name — destruction does NOT delete the GL object; it is a typed, non-copyable identity for one. Copying is disabled so a name is never duplicated implicitly; moving transfers the name and zeroes the source, leaving the moved-from handle invalid().

Template Parameters
TagPhantom type distinguishing handle kinds; see sog::gfx handles in Handles.hpp (e.g. VertexArrayHandle = GLHandle<VertexArrayTag>).
Attention
value 0 is the GL "no object" name; valid() (and operator bool) report false for it, and a default-constructed handle is therefore invalid.
See also
sog::gfx::Handles.hpp for the concrete handle types
