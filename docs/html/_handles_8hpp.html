Detailed Description

Defines the engine's typed OpenGL object handles (vertex arrays, buffers, shaders, textures, framebuffers, renderbuffers).

Each handle is a GLHandle<Tag> specialized with a distinct empty tag type, so a TextureHandle cannot be passed where a ShaderHandle is expected even though both wrap a GLuint.
