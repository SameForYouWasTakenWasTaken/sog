Detailed Description

template<shader_type>
class sog::gfx::Shader< shader_type >

A single compiled GL shader stage, templated on its shader_type.

Owns one GL shader object (identified by a ShaderHandle). Call createFromSource() or createFromFile() to compile; either throws sog::graphics_error if compilation fails (with the driver's info log) or the file cannot be opened. The GL object is deleted on destruction.

The stage is fixed at compile time by the template parameter, so a VertexShader can only hold vertex code, a FragmentShader only fragment code, and so on.

Template Parameters
StageWhich shader stage this object represents (from sog::shader_type).
Note
Compile status is checked after each create* call, so a Shader is always either freshly compiled or has already thrown.
See also
sog::VertexShader, sog::FragmentShader, sog::ShaderProgram
