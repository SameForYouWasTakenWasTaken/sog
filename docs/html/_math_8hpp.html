Detailed Description

Re-exports the GLM math types the engine uses under the sog::math namespace (Vec2/Vec3/Vec4, Mat3/Mat4, glm::value_ptr).

All engine code should refer to sog::math::Vec3 and friends rather than glm directly, so the underlying math library stays replaceable from one place.
